# Luxe Project Hub
Modern architecture & construction project portal (React + Vite).
Rebuilt from MyPatientHub using the Luxe Studio brand: images, gold/bronze palette, Playfair/Poppins/Bebas fonts, copy.

Run: `npm install && npm run dev`  ·  Build: `npm run build`

Pages: Login, Signup, Dashboard, Site Schedule, Find Specialist, Find Site (map), Chat (+video call),
Materials, Contractors, My Projects (3-step wizard), Billing, Settings. Light/dark theme included.
